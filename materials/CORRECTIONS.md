# Corrections to Verbatim Materials

This document records information in `ALL_SLIDES.md` (and other verbatim transcripts under `materials/`) that has become outdated or is otherwise known to be inaccurate. The transcripts themselves are kept faithful to the original lecture decks; corrections live here so the audit trail and the source of truth stay separate.

Compare with the inline `<!-- transcription-audit: -->` blocks in the transcripts, which document fidelity-of-transcription decisions only — *not* corrections to the underlying content.

## Format

Each entry: heading naming the affected slide section, what the slide says, what is currently correct, and a brief source note.
