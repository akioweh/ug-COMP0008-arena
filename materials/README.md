# Materials

Curated bundle of materials covering the full COMP0008 module.

Currently contains:

- `ALL_SLIDES.md` — complete transcript of the lecture slides for all 10 weeks.
- `READING_TOPICS.md` — reading list and topic overviews from the supplementary textbook readings (essential for the concurrency half, weeks 6–10).
- `MIPS_cheat_sheet.pdf` -- the reference sheet for MIPS instructions that will be provided during the exam.
- `LORE.md` — information from outside the verbatim materials above (lecturer Q&A, office-hours clarifications, exam conventions, and corrections to outdated slide content). Treat as required reading alongside the lectures.

## Additional materials (read on demand)

These are not part of the default reading bundle. Consult them when directly relevant — e.g. when working through practice questions, verifying understanding, or checking exam format.

- `past_papers/` — past exam papers for 2023, 2024, and 2025. 
- `exercise_sheets/` — problem sheets (formative coursework) CW1–CW6, each combining the question sheet and model answers in a single file.
